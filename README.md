# Start

### Version 11

Starting to embrace hosting my own things so the new start site aims to showcase this.
Shows the state of the server it's hosted on, other coolify projects, time in bst+jst, next events in my calendar (fastmail), currency of gbp to usd,jpy,eur and my wanikani reviews.

Envs required for certain cards:
```
COOLIFY_API_URL="https://coolify.example.com/api/v1"
COOLIFY_API_TOKEN=""

FASTMAIL_CALDAV_USERNAME="you@example.com"
FASTMAIL_CALDAV_PASSWORD=""
FASTMAIL_CALDAV_URL="https://caldav.fastmail.com/dav/calendars/user/you@example.com/calendar-id/"
FASTMAIL_CALENDAR_LIMIT="6"
FASTMAIL_CALENDAR_LOOKAHEAD_DAYS="31"

WANIKANI_API_TOKEN=""
```

I use helium so set your newtab page by pointing `helium://flags/#custom-ntp` to whereever you are hosting this.
